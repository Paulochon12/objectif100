# Objectif 100 %

Checklist gratuite pour suivre sa progression à 100 % dans GTA 6 (site de fans non officiel).

- Progression enregistrée dans le navigateur (localStorage), sans compte
- Transfert entre appareils par code de sauvegarde
- Objectifs personnels dans chaque catégorie

## Lancer en local

```bash
npm install
npm run dev
```

## Mettre à jour les listes

Les listes sont dans `src/data/checklist.ts`. Garder les `id` stables (ils servent à retrouver la progression des joueurs)
et ne reprendre que des faits (noms, lieux), jamais le texte d'un autre guide.

## Règles de marque

Pas de « GTA », « Vice City » ni logo/image officiels dans le nom, le domaine ou les visuels.
Mention de non-affiliation obligatoire (pied de page).
